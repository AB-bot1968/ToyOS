# Проверка ToyOS v67.11-B FIX28

Контрольная база: FIX27, которая по runtime-тесту корректно проходит 8RT без MT и 4MT+8RT, стартовые MISS/SKIP = 0.

## Главная регрессия MTSTOP ALL
1. Запустить 4 MT задачи и убедиться, что они работают.
2. Запустить 8 RT задач через F10 и убедиться, что RTSTAT/MTSTAT обновляются.
3. Ввести `mtstop all` и нажать Enter ОДИН раз.
4. Ожидается немедленно `mtstop: all stopped`, затем `toy0>` и рабочий ввод. Второй Enter не требуется.
5. `mtlist` не должен показывать активные MT; 8 RT должны продолжать работать.
6. Проверить `rtstat watch`, выход ESC и обычные команды shell.

## Дополнительно
- 4MT без RT -> `mtstop all`: немедленный возврат после одного Enter.
- 4MT+8RT -> `mtstop MT1`, затем `mtstop all`.
- После `mtstop all` снова `execmt` 4 задач: новая MT-сессия должна запускаться нормально.
- Проверить регрессии FIX27: стартовые MISS/SKIP при 8RT без MT и 4MT+8RT не должны получать искусственные большие значения.
