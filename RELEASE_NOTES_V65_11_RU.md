# Toy OS v65.11

Добавлен необязательный `/AUTOSTART.SH` в FAT16 root. Shell проверяет его сразу
после входа в Ring 3 и выполняет непустые строки общим командным обработчиком.
По умолчанию сценарий запускает `exec VGADRV.EXE SPLASH.RAW`. При отсутствии
файла shell стартует по старому пути с приветствием и help.

После `SYS_VIDEO_TEXT` позиция kernel-консоли установлена на строку 24 для
`VGADRV: OK` и строку 25 для `toy0>` в левом нижнем углу.

### Исправление проверки команд AUTOSTART

В общий обработчик `execute_line()` добавлена строгая граница ответственности: функция получает уже сформированную строку и больше не вызывает `readline()`. Поэтому строки `AUTOSTART.SH` не теряются из-за чтения клавиатуры и выполняются последовательно. Ввод с клавиатуры остался только в интерактивном `shell_loop()`.
