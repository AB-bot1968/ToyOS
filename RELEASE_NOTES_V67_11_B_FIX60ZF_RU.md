# ToyOS v67.11-B FIX60ZF — совместная работа MT + RT + консоль

Исправлена точка возврата RT-задачи, запущенной непосредственно из ожидающего
`SYS_CONSOLE_READ`. Ранее `rt_switch_to_shell()` мог перед восстановлением
ожидающей консоли сразу передать управление готовой MT-задаче. При длительной
смешанной нагрузке MT+RT это делало прогресс shell зависимым от квантов MT и
момента IRQ0, тогда как фоновые SONAR/COM задачи продолжали работать.

С FIX60ZF ожидающий shell всегда восстанавливается первым (`EAX=2`), а MT
получает следующую штатную Ring-3/IRQ0 возможность. Политика приоритета RT не
изменена.

Добавлен `TST/TESTMRT.TST` — отдельная регрессия совместной работы 2 MT + 1 RT
с проверкой MT progress, RT completed-job/DUMP и выполнения foreground-команд.
Acceptance manifest теперь содержит 44 теста. Старые тесты не удалялись.

`TOYOS_ARCHITECTURE_VISION.md` дополнен русскоязычным архитектурным инвариантом
владения foreground-консолью при смешанной MT/RT нагрузке.
