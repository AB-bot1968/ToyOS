# Проверка v67.11-B-FIX10

Основной тест: запустить только `SENSOR1.EXE 10 10 1`, затем выполнять `RTSTAT`, `RTSTAT WATCH`, `RTSTAT DUMP`.

Ожидание: foreground shell не должен задерживать READY RT-задачу. Для пустого цикла SENSOR1 значения MISS/SKIP должны оставаться 0 при нормальной работе; JOBS должен расти, INT быть около 1 RT tick. DUMP и RTSTAT используют одинаковые накопительные значения MISS/SKIP.

Исправление находится в IRQ0 scheduler path: Ring-3 shell теперь может быть вытеснен READY RT-задачей независимо от `rt_shell_waiting`; `rt_switch_to()` сохраняет прерванный Ring-3 shell frame. Ring-0 frame по-прежнему не используется как пользовательский контекст.

Каталог `build/` удалён из релизного архива как каталог генерируемых проверочных файлов.
