# Toy OS v61.2 — увеличение резерва kernel slot

## Исправление

В v61.2 резерв под raw kernel увеличен с 64 до **128 секторов (64 KiB)**.
Это сделано с запасом для дальнейшего развития ядра и файловой подсистемы.

Новый layout начала диска:

- LBA 0 — BIOS boot sector;
- LBA 1..128 — kernel slot;
- LBA 129 — временный scratch-сектор для syscall-тестов;
- LBA 130 — FAT16 boot sector;
- далее — FAT #1, FAT #2, root directory и data area.

Загрузчик читает kernel двумя DAP-запросами по 64 сектора:
LBA 1..64 в 0000:7E00 и LBA 65..128 в 1000:7E00.
Это сохраняет совместимость с BIOS, ограничивающими один запрос 64 секторами,
и оставляет точку входа ядра на 0x7E00.

## Контрольные условия

- `kernel.bin` не должен превышать 65536 байт;
- boot sector обязан иметь размер 512 байт и сигнатуру 55 AA;
- FAT16 должен начинаться строго с LBA 130;
- scratch LBA 129 не должен пересекаться с FAT16;
- существующая FAT16 структура каталогов и cwd/cd/pwd не изменяется.
