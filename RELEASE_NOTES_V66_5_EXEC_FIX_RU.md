# Toy OS v66.6 — исправление запуска NETDRV.EXE

## Причина

Код `4294967293` является unsigned-представлением `-3`, то есть `EXE_ERR_OPEN`.
Это означает, что ядро не смогло открыть `NETDRV.EXE` на этапе `SYS_EXEC_ARGS`,
и до `program_main()` NETDRV.EXE выполнение не доходило.

## Исправление

Команда `exec NETDRV.EXE ...` теперь сначала запускает гарантированную копию
`BIN/NETDRV.EXE`, которая добавляется сборочным скриптом в каждый v66-образ.
Для совместимости со старыми образами оставлен резервный запуск корневого
`NETDRV.EXE`.

При ошибке shell теперь печатает фактический код загрузчика, а не только
общее `FAIL`.

Рабочую сетевую логику NE2000/ARP/IPv4/UDP не изменяем.
