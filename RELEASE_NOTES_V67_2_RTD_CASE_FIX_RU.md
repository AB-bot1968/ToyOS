# Release Notes — ToyOS v67.2

## Исправление

Исправлен запуск RTD-команд, в которых имя целевой программы введено строчными буквами.

Теперь `sensor1.exe`, `Sensor1.Exe` и `SENSOR1.EXE` приводятся RTD к одному каноническому ASCII-имени перед `SYS_RT_START`.

## Совместимость

- syscall ABI не изменён;
- формат `rt_start_request_t` не изменён;
- FAT16 не изменён;
- shell history не изменена;
- аргументы RTD не изменяются.
