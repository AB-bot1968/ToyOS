# Toy OS v62.2 — исправление `ls` для относительного пути

## Исправленная ошибка

В v62.1 команда shell `ls` вызывала `SYS_LS` с относительным путём `.`.

Модуль `path_normalize()` корректно преобразовывал `.` в корневой путь `/`,
но старая реализация `fat_ls()` сначала проверяла исходную строку. Для `.`
она пыталась выполнить `fat_lookup_path(".")`. Корень FAT16 не является
обычной directory entry, поэтому поиск закономерно завершался ошибкой и shell
печатал:

```text
ls: FAIL
```

## Исправление

`fat_ls()` теперь в самом начале нормализует входной путь относительно
`fat_cwd` и дальше работает только с каноническим абсолютным путём.

Поэтому согласованно работают:

- `ls`
- `ls .`
- `ls ..`
- `ls /`
- `ls PATH`
- относительные пути из текущего каталога
- абсолютные пути

Для корня `/` `fat_ls()` сразу использует FAT16 root directory и не требует
directory entry для ROOT.

## Регрессии

Добавлена `check69.sh`, которая проверяет наличие исправленной схемы в kernel
и сохранение вызова `sys_ls_path(".")` в shell.

Проверены отдельно:

- freestanding 32-bit компиляция `src/path.c`;
- freestanding 32-bit компиляция `src/kernel.c`;
- строгая host-компиляция `tools/pathcheck.c + src/path.c`;
- `pathcheck`: `PASS: v62 path module regression`;
- `check69.sh`: `PASS: v62.2 ls relative-dot regression`.

Полную сборку именно в Windows 7 + W64DevKit x86 необходимо выполнить в
целевой среде; текущая Linux-среда намеренно не выдаёт себя за W64DevKit.
