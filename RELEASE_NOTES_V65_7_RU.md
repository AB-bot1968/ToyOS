# Toy OS v65.7 — исправление VGA splash / возврата в текстовый режим

## Изменения

1. `SPLASH.RAW` уменьшен до 160x100 пикселей, 8 bit/pixel, 256 цветов: ровно 16000 байт.
2. `VGADRV.EXE` продолжает использовать стандартный VGA Mode 13h (320x200x256), но каждый пиксель ресурса выводится как блок 2x2. Это позволяет делать крупные пиксельные элементы и читаемый логотип без потери совместимости с Mode 13h.
3. Kernel перед `SYS_VIDEO_MAP` сохраняет фактические регистры VGA: Misc Output, Sequencer, CRTC, Graphics Controller, Attribute Controller и полную DAC-палитру 256*3.
4. `SYS_VIDEO_TEXT` восстанавливает сохранённое аппаратное состояние, а не пытается угадать BIOS-таблицу text mode. При восстановлении IRQ временно запрещаются, чтобы не допустить обращения к текстовой консоли во время перестройки VGA.
5. После восстановления kernel очищает `B8000` и обновляет курсор; только затем `VGADRV` снимает VRAM mapping и пишет `VGADRV: OK`.
6. Добавлена регрессия `check88.sh`.

## Команда

```text
exec VGADRV.EXE SPLASH.RAW
```

На заставке отображается подсказка `PRESS ANY KEY`; любая клавиша должна вернуть исходный текстовый режим.

## Ограничение среды

Полный runtime boot-test на Windows 7 + W64DevKit x86 + QEMU в текущей Linux-среде не выполняется. Здесь контролируются компиляция исходников, проверки формата ресурсов и статические регрессионные тесты.
