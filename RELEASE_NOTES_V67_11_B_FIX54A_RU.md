# ToyOS v67.11-B FIX54A — Infrastructure Hardening

Исправление кандидата FIX54 после runtime-регрессии в QEMU.

## Исправлено
- `mtstop MTn` при остановке последней MT-задачи теперь завершает скрытую MT-сессию (`sched_active`, `mt_session_active`, `mt_session_count`) так же, как явное завершение сессии. Ранее следующий `execmt` получал BUSY, хотя `MT_ACTIVE=0` и handles уже были очищены.
- `START MT N` в TST теперь проверяет фактически запущенное число MT-процессов и не считает сам возврат из `execmt_command()` доказательством успеха.
- `TESTINF.TST` дополнен регрессией `stop final MT -> immediate START MT`, воспроизводящей обнаруженную межтестовую ошибку без маскирующего reset.
- В `tools/` добавлены предоставленные пользователем исходники/скрипты `win_sendfile_w64devkit_ru` (README/CHECK переименованы во избежание конфликта общих имён; каталог Python сохранён).

Архитектура свободного Ring3-доступа к I/O портам через syscall 13/14 не изменена.
