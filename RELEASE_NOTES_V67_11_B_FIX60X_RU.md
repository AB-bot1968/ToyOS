## Итоговая консольная сводка FAIL

Пакетная команда `test` теперь после завершения всех тестов выводит компактную сводку: имя каждого теста с ошибкой и номер каждой ошибочной строки. Полный вывод тестов по-прежнему идет непосредственно на консоль; `TST.LOG` не создается. Для сводки используется только фиксированная таблица до 128 записей `{имя теста, строка}`, без буферизации текста тестового отчета и без записи на диск.
