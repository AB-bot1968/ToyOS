# Toy OS v66.2 — исправление UDP-телеметрии

## Что исправлено

1. Slave1/Slave2 больше не завершаются, если Master выключен. Slave работает независимо и периодически повторяет ARP к адресу Master.
2. Master можно штатно остановить клавишей ESC. Добавлен неблокирующий syscall `SYS_CONSOLE_POLL=37`; ESC передаётся из IRQ1 в очередь клавиатуры, когда нет активной `execq`.
3. При потере Master Slave снова помечает MAC как неизвестный и повторяет ARP.
4. Для двух ПК рекомендуется Windows Network Bridge между физическим Ethernet/Wi-Fi интерфейсом и `tap0`: TAP остаётся локальным интерфейсом, а bridge переносит Ethernet-кадры между QEMU и реальной LAN.

## Важно

Эта версия не меняет базовый v65.15 и не меняет существующий TCP/HTTP режим NETDRV.
