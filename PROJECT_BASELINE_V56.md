# PROJECT BASELINE v56

## Контрольная точка

v56 является точкой отката, полученной строго из v55.

## Единственное изменение

В `src/comdrv.c` тайм-аут ожидания первого байта в `RECV` увеличен с 5 секунд (`250` тиков при 50 Гц) до 10 секунд (`500` тиков при 50 Гц).

Тайм-аут после первого байта оставлен 1 секунда (`50` тиков).

## Предыдущие точки

- v50 — базовая стабильная точка.
- v55 — стабильная точка с рабочим COMDRV и проверенной передачей файлов байт-в-байт.
- v56 — та же версия с единственным изменением timeout первого байта.
