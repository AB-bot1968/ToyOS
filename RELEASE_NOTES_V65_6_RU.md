# Toy OS v65.6 — нормальный возврат VGA splash в текстовый режим

## Исправление

В v65.5 пользовательский VGADRV самостоятельно пытался восстановить VGA-регистры из Ring 3. На реальном запуске это приводило к графической порче после нажатия клавиши: драйвер не гарантировал полный и атомарный возврат к стандартному 80x25.

В v65.6 возврат режима перенесён в kernel через новый syscall:

`SYS_VIDEO_TEXT = 35`

Kernel выполняет полный набор стандартных VGA-регистров цветного текстового режима 80x25, восстанавливает стандартную 16-цветную DAC-палитру, а затем очищает B8000 и обновляет аппаратный курсор. После этого VGADRV снимает доступ к VRAM через `SYS_VIDEO_UNMAP` и завершает EXE1.

## Поведение

Команда:

```text
exec VGADRV.EXE SPLASH.RAW
```

показывает 320x200x256 splash из обычного файла FAT16. В самой картинке размещена инструкция:

`Press any key to return to text mode...`

Драйвер ждёт любую клавишу. Символ клавиши не передаётся shell: он потребляется `SYS_CONSOLE_READ`, после чего kernel возвращает VGA в текстовый режим и очищает экран.

## Графический ресурс

`resources/SPLASH.RAW` — ровно 64000 байт.

`resources/SPLASH_PREVIEW.png` — визуальный preview того же 320x200 ресурса.

Заставка содержит логотип `TOY OS`, краткие сведения о системе и инструкцию возврата в текстовый режим.
