# Проверка ToyOS v67.11-B FIX17

1. Запустить `execmt MT01.EXE MT02.EXE MT04.EXE` одной командой.
2. После старта MT-задачи не должны выводить в консоль ни одного символа.
3. `mtlist` должен показывать MT1/MT2/MT3 с именами MT01.EXE/MT02.EXE/MT04.EXE.
4. `mtdata MT1`, `mtdata MT2`, `mtdata MT3` должны вернуть соответственно `MT01:RUN;`, `MT02:RUN;`, `MT04:RUN;` после первого кванта каждой задачи.
5. Задачи не завершаются самостоятельно: повторный `mtlist` продолжает показывать их.
6. `mtstop MT2` останавливает только вторую позицию; ее последний MTDATA сохраняется.
7. `mtstop ALL` завершает MT-сессию и очищает MTDATA.
8. Если до `mtstop ALL` выполнить новый `execmt ...`, shell должен сообщить `execmt: session active; use mtstop ALL before a new execmt`, а не `FAIL 4294967295`.
9. Параллельно с SENSOR1..4 проверить, что RTSTAT/RTDATA не изменили поведение.
