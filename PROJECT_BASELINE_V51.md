# Toy OS — Project Baseline v51

v51 является продолжением рабочей версии v50.

## Новая функция

Добавлен `COMDRV.EXE1` — первый пользовательский драйвер COM-порта.

- COM1..COM4;
- 115200 baud;
- 8 data bits, no parity, 1 stop bit (8N1);
- polling без UART IRQ;
- передача полного файла;
- приём байтов в автоматически создаваемый/очищаемый FAT16-файл;
- ограниченный idle/tx timeout, исключающий бесконечное зависание.

## Аргументы EXE1

Добавлены syscall 25 `SYS_EXEC_ARGS` и syscall 26 `SYS_EXEC_QUEUE_ARGS`.
Это минимальное расширение ABI, необходимое для реальных трёх параметров EXE1
и их сохранения при последовательном `execq`. Старые syscall 1..24 не менялись.

## Совместимость

Существующие `exec`, `execq`, `execmt`, `ls`, FAT16, планировщик, Ring-3,
CR3-изоляция и существующие EXE1 сохраняются.

## Сборка

Штатная сборка: Windows 7 + W64DevKit i686 + QEMU. Linux-окружение этой
сессии используется только для статической проверки исходников; финальная
проверка образа выполняется штатным Windows toolchain проекта.
