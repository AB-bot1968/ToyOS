# Проверка FIX31

1. Запустить 25 MT задач.
2. Несколько секунд ничего не вводить в приглашении `toy0>`.
3. Выполнить `MTSTAT`, запомнить D/Q/C.
4. Снова 2-3 секунды оставить shell в ожидании ввода и повторить `MTSTAT`.
   Все выполняющиеся MT должны продолжать накапливать статистику; ожидание клавиатуры больше не должно останавливать MT.
5. Выполнить `MTSTAT WATCH`: темп изменения D/Q/C должен быть сопоставим с обычным MTSTAT за одинаковый реальный интервал.
6. Проверить ESC из MTSTAT WATCH.
7. Повторить с 8 RT + 25 MT: RTSTAT не должен получать новые MISS/SKIP из-за FIX31, MTSTAT должен изменяться.
8. Выполнить `MTSTOP ALL`: команда должна завершиться с первого Enter (регрессия FIX28 недопустима).

Полная runtime-проверка должна выполняться на штатной W64DevKit/QEMU конфигурации проекта.
