# ToyOS v67.5 — Release Notes

## Исправление

Исправлено положение сообщения успешного завершения графической заставки.

После нажатия клавиши:

`VGADRV: OK toy0> `

теперь начинается с колонки 0 последней строки текстового режима 80x25.

Изменён только успешный путь `VGADRV.EXE`. Архитектура и syscall ABI не изменялись.
