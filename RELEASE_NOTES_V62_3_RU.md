# Toy OS v62.3 — защита `rmdir` и текущего каталога

## Исправление

В `SYS_RMDIR` добавлена защита от удаления:

- ROOT `/`;
- текущего каталога `cwd`;
- любого родительского каталога текущего `cwd`.

Перед проверкой каталогов путь нормализуется общим модулем `src/path.c`, поэтому
защита одинаково работает для `rmdir .`, `rmdir ..`, абсолютных путей и
относительных путей с несколькими уровнями.

## Почему это необходимо

`fat_cwd` хранит текущий каталог в виде канонического пути. Если удалить сам
каталог или одного из его предков, строка `fat_cwd` станет указывать на объект,
которого больше нет. Это нарушает согласованность состояния ядра и может
сломать последующие операции `ls`, `cd`, `cat`, `mkdir` и другие операции с
относительными путями.

## Ожидаемое поведение

Если текущий каталог `/A/B`:

```text
rmdir .       -> FAIL
rmdir ..      -> FAIL
rmdir /A      -> FAIL
rmdir /A/B    -> FAIL
rmdir /A/C    -> OK, если каталог /A/C пуст
```

Из ROOT `/` попытка `rmdir /` также должна завершаться `FAIL`.

## Регрессия

Добавлена `check70.sh`, проверяющая наличие нормализации пути и всех трёх
уровней защиты `rmdir`.
