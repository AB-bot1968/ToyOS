# ToyOS v67.11-B FIX60ZEI — стабильный baseline

Зафиксированная стабильная версия ToyOS после длительной серии исправлений смешанного RT/MT/console и SONAR pipeline.

Подтверждено runtime-тестированием:

- 45/45 acceptance-тестов;
- стабильная длительная работа 2 MT + 4 RT;
- интерактивная консоль без выявленных зависаний;
- устойчивый `SONARLOG`;
- корректный live-viewer через `execmt SONARVWR.EXE`;
- автоматическое восстановление приглашения `toy0>` после фонового вывода.

Ключевой архитектурный принцип релиза: стабильный scheduler не изменяется ради искусственных test-harness busy-wait сценариев; acceptance orchestration обязана воспроизводить реальные scheduler boundaries.

Git tag: `v67.11-B-FIX60ZEI`.

Полное описание эволюции архитектуры: `TOYOS_ARCHITECTURE_VISION.md`.
