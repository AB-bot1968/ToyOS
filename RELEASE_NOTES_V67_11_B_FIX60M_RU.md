# ToyOS v67.11-B FIX60M

Исправлено зависание после первого успешно принятого SONAR/Modbus ответа.

FIX60J добавил SYS_MT_YIELD в успешный путь SONARDRV. Это создало второй механизм возврата foreground-контекста параллельно штатной IRQ0/PIT-преэмпции. После получения валидного кадра драйвер входил в sched_yield(), который восстанавливал сохранённый shell frame из int80-контекста; на реальном QEMU/com0com это проявлялось как потеря интерактивной консоли сразу после первой строки клиента.

FIX60M удаляет cooperative yield из SONARDRV. Фоновый драйвер снова переключается только штатным MT scheduler по IRQ0 с квантом 20 ms. UART остаётся полностью polling, IRQ4 выключен, SONARDRV ничего не печатает в консоль.

Добавлен TESTSONM.TST и host-проверка check_fix60m_sonar_no_yield.sh. Исходный архив не содержит build/ и объектных файлов.
