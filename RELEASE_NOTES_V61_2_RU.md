# Toy OS v61.2 — исправление загрузки расширенного kernel slot

## Критическое исправление

В v61.2 второй 64-секторный BIOS DAP загружал данные по адресу `1000:7E00`
(физический `0x17E00`). Это было ошибкой: первые 64 сектора занимают
непрерывную область `0x7E00..0x0FDFF`, поэтому второй блок должен начинаться
с физического `0x0FE00`.

В v61.2 второй DAP использует `0800:7E00`, то есть физический `0x0FE00`.
В результате kernel.bin снова находится в памяти непрерывно, и переход
на `0x7E00` после включения protected mode корректен.

## Kernel slot

- LBA 1..128: kernel slot, 128 секторов = 64 KiB.
- LBA 129: scratch.
- LBA 130: FAT16 boot sector.

## Проверка

Проверяются оба DAP, их LBA, количество секторов и непрерывность адресов
`0000:7E00` + `0800:7E00`. Дополнительно выполняются стандартные проверки проекта.
