# ToyOS v67.1 — регистронезависимый ввод команд

## Назначение

В интерактивной Ring-3 консоли ToyOS имена команд теперь распознаются без
учёта регистра ASCII. Это относится как к встроенным командам shell, так и к
именам исполняемых EXE1, передаваемым через `exec`, `execq` и `execmt`.

## Изменение 1 — единое ASCII-сравнение в `src/user_shell.c`

Добавлена функция `ascii_fold()`.

Она преобразует только диапазон `A..Z` в `a..z`. Остальные байты возвращаются
без изменений. Это сознательно не является Unicode case-folding: командная
оболочка ToyOS использует ASCII-имена, а файловая система — FAT 8.3.

Изменены функции `eq()` и `prefix()`:

- `eq()` сравнивает строки без учёта регистра;
- `prefix()` сравнивает без учёта регистра только командный префикс;
- исходная строка пользователя физически не изменяется.

Таким образом, существующая архитектура shell не меняется, а таблица команд
и ABI syscall остаются прежними.

## Изменение 2 — встроенные команды

Поскольку `execute_line()` уже использует `eq()` и `prefix()` для распознавания
команд, отдельные ветви для `HELP`, `Help`, `HELP`, и т. п. не добавляются.

Например, одинаково распознаются:

```text
help
HELP
Help
hElP

ls
LS
Ls

exec
EXEC
ExEc
```

## Изменение 3 — исполняемые файлы

Команды вида `exec RDT.EXE` и специализированные обработчики `LOADER.EXE`,
`COMDRV.EXE`, `NETDRV.EXE`, `VGADRV.EXE`, `RTD.EXE` также проходят через
регистронезависимый `prefix()`.

Кроме того, уже существующая нормализация путей в `src/path.c` переводит
компоненты пути в верхний регистр перед FAT16 lookup. Поэтому имя EXE на
файловой системе также находится независимо от регистра вводимого имени.

Физическое имя файла на диске не переименовывается и не дублируется.

## Что намеренно НЕ меняется

Регистронезависимым становится именно имя команды/программы.

Аргументы команды не преобразуются. Например:

```text
write Test.TXT AbCdEf
```

передаёт имя и текст дальше в исходном виде. То же относится к параметрам
EXE1 и к содержимому файлов.

## Совместимость с историей команд

Механизм истории команд глубиной 1 не менялся.

Если пользователь вводит:

```text
rDt.ExE
```

то клавиша `↑` возвращает именно `rDt.ExE`, поскольку нормализация выполняется
только при сравнении, а не при редактировании или сохранении строки.

## ABI и ядро

Новые syscall не добавляются.

Номера syscall, форматы аргументов, INT 80h ABI, загрузчик EXE1, планировщик,
FAT16 и layout диска не изменяются.

## Проверка

Добавлен `check127.sh`, который проверяет наличие case-insensitive helper'а,
его использование в `eq()`/`prefix()`, отсутствие изменения syscall ABI и
наличие регистронезависимых путей для встроенных и EXE-команд.

Полная сборка `build.sh` дополнительно проверяет итоговый бинарный образ.
