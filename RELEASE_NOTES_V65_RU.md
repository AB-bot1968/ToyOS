# Toy OS v65 — Ring-3 VGADRV + внешний FAT16-ресурс

v65 продолжает чистую архитектурную базу v64. Существующие FAT16, cwd/path,
`rm`, `cp`, `exec`, очереди и paginated `help` не заменяются.

## Новое

- Добавлен `src/vgadrv.c` — обычный EXE1/Ring-3 видеодрайвер.
- Добавлены системные вызовы:
  - `SYS_VIDEO_MAP = 32` — временно даёт текущему EXE доступ к VGA VRAM;
  - `SYS_VIDEO_UNMAP = 33` — снимает этот доступ.
- VRAM `0xA0000..0xAFFFF` отображается в user page table только на время
  работы обычного EXE1-драйвера.
- Драйвер использует существующие `SYS_PORT_OUT8/SYS_PORT_IN8`, поэтому
  прямой I/O из CPL3 не требуется и IOPL остаётся равным 0.
- `exec VGADRV.EXE FILE` передаёт имя файла через существующий `SYS_EXEC_ARGS`.
- `SPLASH.RAW` хранится как обычный файл FAT16 и имеет размер 64000 байт:
  320x200, 8 bit/pixel, 256-цветный индексированный framebuffer.
- После вывода изображения драйвер ждёт клавишу, восстанавливает VGA text
  mode 80x25, снимает mapping VRAM и завершает EXE1.

## Почему картинка не затирается ростом FAT16

`SPLASH.RAW` больше не находится в специальной области диска. Это обычный
FAT16-файл. FAT allocator выделяет ему собственные кластеры; расширение
файловой области FAT16 использует свободные кластеры и не перезаписывает
существующую запись файла при корректной работе файловой системы.

## Проверка

Минимальный ручной тест после загрузки:

```text
ls
filesize SPLASH.RAW
exec VGADRV.EXE SPLASH.RAW
```

После отображения нажмите любую клавишу. Должен восстановиться текстовый
экран, после чего shell продолжит работу и покажет следующий `toy0>`.

Для проверки произвольного файла размер должен быть ровно 64000 байт.
Формат v65 намеренно простой: заголовка и встроенной палитры нет.

## Важное ограничение текущего этапа

Полный target build рассчитан на Windows 7 + W64DevKit x86. В среде разработки
Linux x86_64 этот `build.sh` специально останавливается на проверке target,
поэтому здесь выполнены независимые 32-bit freestanding compile-проверки,
hosted проверки утилит и статические регрессии, но не эмуляционный boot-test.
