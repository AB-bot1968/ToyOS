Toy OS v60.2 — контроль сборки

Исправлены две причины нестабильности предыдущего этапа:
1. mkfat16 просматривал только 16 записей ROOT DIRECTORY вместо всех 512;
2. размещение кластеров проверялось относительно теоретического предела FAT16,
   а не фактического размера образа.

Системный состав ROOT дополнен BOOT.BIN. В ROOT также находятся HELLO.EXE,
COMDRV.EXE, LOADER.EXE, NETDRV.EXE, NET.CFG и все существующие Q*/MT* тесты.

Доступные проверки в среде разработки:
- shell syntax check для build.sh/check62.sh;
- mkfat16.c: syntax-only;
- mkfat16.c: обычная объектная компиляция;
- mkfat16.c: объектная компиляция с -fno-omit-frame-pointer;
- kernel.c/user_shell.c: три компиляционных прохода в 32-битном режиме;
- фактическое создание тестового FAT16-образа с 43 файлами, включая записи
  ROOT после 16-й позиции;
- fat16check для F20.TXT, F40.TXT, BOOT.BIN, BIN и BIN/F02.TXT.

Полная нативная сборка Windows 7 + W64DevKit x86 должна быть дополнительно
выполнена пользователем в целевой среде. Здесь такой результат не заявляется
без наличия соответствующего toolchain.
