# Toy OS v65.10 — исправление возврата VGA text mode

## Причина дефекта

После выхода из VGA Mode 13h экран переключался частично: курсор был виден, но записи в `B8000` не интерпретировались как обычная текстовая память, поэтому появлялись вертикальные полосы и вводимые символы не отображались.

Корень проблемы находился в двух связанных операциях восстановления font plane 2 и текстовой адресации VGA:

1. При чтении/записи font plane 2 использовалось `GC06=04h`, хотя окно `A0000` требует `GC06=00h`.
2. После загрузки font plane оставалось `SEQ04=07h`. Это режим последовательной адресации, нужный для загрузки шрифта, но не штатная odd/even-адресация текстового режима.

## Исправление

Перед первым запуском graphics mode kernel:

- выбирает `SEQ02=04h` (CPU writes only to plane 2);
- устанавливает `SEQ04=07h` для последовательного доступа к font memory;
- выбирает `GC04=02h` для чтения plane 2;
- устанавливает `GC05=00h` и `GC06=00h` для окна `A0000`;
- сохраняет 256 символов × 16 строк в RAM.

После возврата из graphics mode:

- выполняется детерминированный mode 03h;
- font plane восстанавливается через те же правильные параметры доступа;
- затем возвращается `SEQ04=03h`;
- `GC04=00h`, `GC05=10h`, `GC06=0Eh` восстанавливают текстовую odd/even-адресацию и окно `B8000`;
- очищается `B8000` и обновляется курсор.

Таким образом после нажатия любой клавиши драйвер снова работает с полноценным VGA 80×25 text mode.

## Ресурс заставки

`resources/SPLASH.RAW` остаётся обычным FAT16-файлом:

- 320×200;
- 256 цветов;
- 1 байт на пиксель;
- 64000 байт.
