# ToyOS v67.7

## Исправление `rm` / `delete` и `ls`

Исправлена ситуация, при которой после успешного удаления файла имя могло продолжать отображаться командой `ls`.

Изменён файловый слой ядра:

- directory entry теперь полностью очищается перед установкой FAT16 marker `0xE5`;
- после удаления дополнительно очищаются возможные дублирующиеся записи с тем же 8.3-именем;
- обработаны ROOT и обычные каталоги;
- syscall ABI не менялся.

Особый регрессионный случай: `010101.TXT`.
