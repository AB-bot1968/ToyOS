# v67.11-B — фоновые RT-задачи

## Жизненный цикл

`F10` запускает очередь подготовленных через `exec RTD.EXE ...` задач. После запуска shell остаётся доступен:

```text
F10
RTD: ... started
...
toy0>
```

RT-задачи продолжают работать независимо от ожидания shell.

## Остановка

```text
rtstat stop
```

останавливает все активные SENSOR-задачи.

```text
rtstat stop sensor1
```

останавливает только SENSOR1.

Команда не очищает собранную статистику.

## ESC

В `rtstat watch` клавиша ESC завершает только режим просмотра. SENSOR1..SENSOR4 продолжают выполняться.

Когда ESC обрабатывается непосредственно RT-задачей, сохраняется существующий механизм её собственного stop request.

## ABI

Используется существующий syscall 43 `SYS_RT_STATUS`.

- `ECX=0xffffffff` + `EBX=0` + `EAX=43`, `EDX=1` — stop all.
- `ECX=0..3` — stop соответствующего RT slot.
- Возвращаемое значение — число остановленных задач; `0xffffffff` — ошибка.

Новые номера syscall не добавляются.
