# ToyOS v67.11-B FIX60L

Исправлена потеря интерактивной консоли после `execmt SONARDRV.EXE`.

FIX60K правильно откладывал первый запуск до возврата `toy0>`, но затем `SYS_CONSOLE_READ` всё ещё непосредственно подменял свой живой syscall-frame кадром MT-задачи (старый механизм FIX31). Для постоянно READY/polling SONARDRV это оставляло foreground shell зависимым от повторно сохраняемого syscall continuation.

FIX60L удаляет прямое переключение shell->MT из `SYS_CONSOLE_READ`. При наличии MT-работы чтение возвращает внутренний код EAX=2 в Ring3; `readline()` оставляет короткое bounded Ring3-окно, а обычный IRQ0 выполняет переключение только с настоящего пользовательского кадра. Клавиша проверяется до hand-off, поэтому ввод shell имеет приоритет.

Добавлены TESTMTL.TST и TESTSONL.TST. Каталог build в исходный архив не включается.
