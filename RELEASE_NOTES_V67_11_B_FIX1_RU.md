# Release Notes — ToyOS v67.11-B-FIX1

Исправлена ошибка интерактивной консоли при работе четырёх фоновых SENSOR RT-задач. Фоновый RT-код больше не пишет периодические сообщения в shell, а F10-запуск RTD выполняется в тихом режиме. Это устраняет гонку вывода с `toy0>` и вводом команд.

База: v67.11-B.
Следующий согласованный этап: v67.11-C RTDATA.
