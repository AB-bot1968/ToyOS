# ToyOS v67.11-B FIX60ZA

Исправлена семантика двух acceptance-тестов после анализа реального прогона FIX60Z.

- TESTACC: проверка RT progress/DUMP отделена от проверки SLOT STOP. Progress проверяется на одной задаче; затем RT очищается, и четыре задачи запускаются заново для независимой проверки 4->3->2->1->0.
- TESTSONP: после достижения 1000 публикаций heartbeat проверяется bounded WAIT (100 ticks), а не мгновенным snapshot. Требование heartbeat >=1000 не ослаблено.
- Остальные 41 TEST*.TST не изменены.
- TST.LOG и B*.TST не используются.
