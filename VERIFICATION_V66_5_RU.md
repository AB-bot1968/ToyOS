# Проверка Toy OS v66.6

## Причина версии

Код `4294967293` является unsigned-представлением `-3` и соответствует
`EXE_ERR_OPEN`. Такой результат означает, что ошибка возникает на этапе
загрузки `NETDRV.EXE`, ещё до входа в `program_main()` сетевого драйвера.

## Исправление

Команда `exec NETDRV.EXE ...` сохраняет прежний пользовательский синтаксис.
Shell сначала запускает гарантированно добавленную сборкой копию
`BIN/NETDRV.EXE`. Если она недоступна, выполняется резервный запуск
корневого `NETDRV.EXE`.

При окончательном отказе выводится фактический код загрузчика.

Сетевая логика NE2000/ARP/IPv4/UDP v66.4 не изменялась.
