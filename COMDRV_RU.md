# COMDRV.EXE1 — первый драйвер COM

## Интерфейс

`exec COMDRV.EXE PORT SEND FILE` — передать весь файл.

`exec COMDRV.EXE PORT RECV FILE` — создать/очистить FILE и принимать байты.

Для `execq` используется тот же набор параметров:

`execq REPEAT COMDRV.EXE PORT SEND FILE`

`execq REPEAT COMDRV.EXE PORT RECV FILE`

или `forever`. Очередь остаётся последовательной: один EXE завершается через `SYS_EXIT`, затем запускается следующий проход.

## UART

COM1..COM4: 0x3F8/0x2F8/0x3E8/0x2E8. Скорость 115200, 8N1. Работа polling без UART IRQ.

Ring-3 не выполняет `IN`/`OUT`: используются только `SYS_PORT_OUT8` (13) и `SYS_PORT_IN8` (14) через `INT 80h`.

Приём автоматически завершается после 1 секунды отсутствия байтов после первого принятого байта; если поток вообще не начался, действует предел 5 секунд. Это исключает вечное зависание.

## ABI аргументов EXE1

Для нового `SYS_EXEC_ARGS` ядро передаёт три указателя в EBX/ECX/EDX. Каждый указывает на строку длиной не более 15 символов.
