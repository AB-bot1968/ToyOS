# ToyOS v67.4 — SPLASH/LS FIX

Исправлены два наблюдавшихся дефекта загрузочного графического сценария:

- ресурс `SPLASH.RAW` теперь открывается VGADRV по абсолютному пути `/SPLASH.RAW`
  с сохранением относительного fallback;
- аварийный выход VGADRV гарантированно восстанавливает text mode до возврата
  в shell;
- после восстановления VGA текстовая консоль очищается и начинается с `(0,0)`;
- AUTOSTART.SH обновлён на `/SPLASH.RAW`;
- добавлена подробная документация `IMAGE_SPLASH_LS_FIX_V67_4_RU.md`.
