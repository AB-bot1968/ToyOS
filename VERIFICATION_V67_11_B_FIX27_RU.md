# Проверка ToyOS v67.11-B FIX27

Контрольная версия FIX26 зафиксирована и не изменяется. FIX27 исправляет только ложную
стартовую статистику RT при пакетном F10.

Основной тест без MT:
1. Подготовить SENSOR1..SENSOR4: period=10 deadline=10, priorities 1,3,5,7.
2. Подготовить SENSOR5..SENSOR8: period=100 deadline=100, priorities 8,9,10,11.
3. F10.
4. Сразу `rtstat`, затем `rtstat watch` 30-60 секунд.
Ожидание: время загрузки восьми RTD не должно превращаться в сотни стартовых SKIP.
При отсутствии реальной перегрузки стартовые MISS/SKIP должны оставаться 0. Если после
старта возникает реальное нарушение срока, оно должно учитываться обычным механизмом.

Регрессия:
- 4MT -> 8RT -> F10: shell не зависает; RT и MT продолжают работать.
- `rtstat watch` и `mtstat watch`, выход ESC.
- RTDATA SLOT1..SLOT8 и MTDATA MT1..MT4.
- Повторный запуск после освобождения слота: новый слот получает новый commit epoch.
- Уже работавшие RT задачи при следующем F10 не должны получать сброс статистики.
