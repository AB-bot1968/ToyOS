# Toy OS v65.3 — исправление комплекта сборки

## Причина

В архив v65.2 по ошибке не попали основные сценарии сборки `build.sh` и
`build.bat`. Поэтому сразу после распаковки команды `build.bat`/`./build.sh`
могли завершаться сообщением `not found` ещё до компиляции исходников.

## Исправление

В v65.3 в корень проекта возвращены:

- `build.sh` — полный сценарий сборки и регрессионных проверок;
- `build.bat` — штатный запуск из x86 W64DevKit под Windows 7.

Отдельного файла `build` нет: имя `build` занято рабочим каталогом сборки.
Это предотвращает самоуничтожение сценария при штатном `rm -rf build`.

Архитектура VGADRV, FAT16, EXE1 и изменения v65.2 не изменялись.
