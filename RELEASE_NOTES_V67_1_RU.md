# ToyOS v67.1 — Case-Insensitive Console Commands

## Базовая версия

`ToyOS_v67_RTD_STAGE6_1_FIX3_CMD_HISTORY.zip`

## Изменение

Консольный Ring-3 shell теперь распознаёт имена команд и исполняемых EXE1 без
учёта регистра ASCII.

Примеры:

```text
HELP
Help
help

RDT.EXE
rdt.exe
RdT.ExE
```

Встроенные команды и специальные формы `exec`, `execq`, `execmt` используют
один механизм сравнения и поэтому не требуют отдельных вариантов написания.

## Сохранение исходной строки

Нормализация выполняется только при сравнении. Строка редактирования не
изменяется. Поэтому история глубиной 1, добавленная в предыдущем изменении,
продолжает возвращать исходный регистр:

```text
toy0> rDt.ExE
```

После `↑` возвращается именно `rDt.ExE`.

## Аргументы

Регистр аргументов не преобразуется. Например, `write Test.TXT AbCd` передаёт
эти данные дальше без изменения.

## Файловая система

Отдельное изменение FAT16 lookup не потребовалось: существующий модуль
`src/path.c` уже канонизирует компоненты пути в верхний регистр перед поиском
FAT 8.3. Поэтому имя EXE также находится независимо от регистра.

## ABI

Syscall ABI, номера syscall, загрузчик EXE1, layout диска, paging, GDT/TSS,
история команд и обработка клавиатуры не изменялись.

## Документация и проверка

- `CASE_INSENSITIVE_COMMANDS_V67_1_RU.md` — подробная документация изменения;
- `check127.sh` — статическая проверка case-insensitive command parsing;
- исходный код содержит комментарии непосредственно возле нового механизма.

Полная `build.sh` в текущей среде не выполняется, потому что она намеренно
требует x86 W64DevKit (`gcc -dumpmachine` с i686/i386 target). Отдельная
компиляция изменённых `src/user_shell.c` и `src/path.c` с 32-битными
freestanding-флагами GCC прошла успешно.
