# Toy OS v66.6 — исправление запуска NETDRV.EXE по абсолютному пути

## Причина

Код `4294967293` соответствует знаковому значению `-3` (`EXE_ERR_OPEN`).
В shell команда `exec NETDRV.EXE ...` передавала сначала относительное имя `BIN/NETDRV.EXE`.
Если текущий каталог Toy OS отличался от `/`, например `/BIN`, ядро пыталось открыть
`/BIN/BIN/NETDRV.EXE` и возвращало ошибку открытия.

## Исправление

Для запуска NETDRV теперь используются абсолютные пути:

- `/BIN/NETDRV.EXE`
- резервный `/NETDRV.EXE`

Пользовательская команда не изменилась:

`exec NETDRV.EXE TELEMETRY SLAVE1 10.66.1.2`

## Требования

- v65.15 остаётся исходной стабильной базой;
- изменяется только обработчик запуска NETDRV в shell;
- подробные русские комментарии сохраняются;
- сетевой стек и UDP-протокол не переделываются.
