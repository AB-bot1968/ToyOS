# Toy OS v66 — минимальная UDP-телеметрия

На базе стабильной v65.15 добавлен минимальный UDP/IPv4 слой в существующий `NETDRV.EXE` без переделки загрузчика, FAT16 и рабочей графики.

## Архитектура

`Ethernet -> NE2000 -> ARP -> IPv4 -> UDP`.

Порт телеметрии фиксирован: **UDP/5000**.

Slave отправляет раз в секунду одну строку вида `SLAVE1 COUNT=... TICK=...` или `SLAVE2 ...`. Master принимает пакеты от `192.168.100.11` и `192.168.100.12` и перерисовывает два фиксированных экранных слота. История пакетов на экране не накапливается.

## Команды

На машине master: `exec NETDRV.EXE TELEMETRY MASTER 5000`

На slave 1: `exec NETDRV.EXE TELEMETRY SLAVE1 192.168.100.10`

На slave 2: `exec NETDRV.EXE TELEMETRY SLAVE2 192.168.100.10`

Для каждой машины в её `NET.CFG` должны быть свой IP и уникальный MAC. Базовая версия файла из v65.15 не заменяется автоматически.

## Важное ограничение первого этапа

Драйвер использует текущую аппаратную модель v65.15 — QEMU **NE2000 ISA** с polling через I/O syscalls. `rtl8139` пока не поддерживается этим драйвером.

Добавлен syscall `36 / SYS_CONSOLE_AT`: безопасная запись фиксированной строки в VGA text 80x25 без изменения курсора shell. Он нужен для телеметрии и не вмешивается в обычный `SYS_CONSOLE_WRITE`.
