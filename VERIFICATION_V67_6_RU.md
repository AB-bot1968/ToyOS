# ToyOS v67.6 — Verification

Проверка исходного кода подтверждает:

- после `SYS_VIDEO_TEXT` курсор начинается с `(0,0)`;
- VGADRV выполняет 23 LF перед `VGADRV: OK `;
- после сообщения выполняется LF;
- shell получает строку 24 для `toy0> `;
- старая схема v67.5, при которой prompt продолжал `VGADRV: OK ` на той же строке, отсутствует;
- syscall ABI не изменён.

Полная `build.sh` требует проектный i686/W64DevKit toolchain.
