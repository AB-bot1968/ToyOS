# ToyOS v67 — RTD Stage 1 FIX6

Исправлено восстановление приглашения shell после завершения detached RT-задачи.

## Проблема
После `SENSOR.EXE -> SYS_EXIT` ядро восстанавливало заблокированный `SYS_CONSOLE_READ` shell, но возвращало `EAX=0`. `readline()` воспринимал это как отсутствие символа и снова входил в ожидание клавиатуры. В результате shell работал, но `toy0> ` визуально не перерисовывался.

## Исправление
`rt_exit()` возвращает специальный внутренний результат `2`. Обычный `SYS_CONSOLE_READ` по-прежнему возвращает только `1` для символа или `0xffffffff` при ошибке. Ring-3 `readline()` распознаёт `2`, печатает `toy0> ` и продолжает ожидание ввода без потребления клавиши.

Существующий EXE1 ABI, EXECMT, PIT 50 Hz и обычный `SYS_CONSOLE_READ` не изменены.
