# ToyOS v67 RTD Stage 1 FIX5

Исправлены две проблемы эксплуатации RTD/SENSOR:

1. `SENSOR.EXE` теперь правильно распознаёт синтетический ESC от `SYS_CONSOLE_POLL`.
   Syscall возвращает ASCII-код нажатой клавиши, поэтому проверка должна сравнивать
   результат с `0x1B`, а не с `1`. После ESC SENSOR печатает `SENSOR: ESC -> stopped`
   и завершает себя обычным `SYS_EXIT`.
2. Необязательный параметр `[DELAY_MS]` остаётся задержкой **старта** SENSOR, а не
   периодом вывода. Команда `exec RTD.EXE SENSOR.EXE 10 10 3 3000` означает запуск
   SENSOR примерно через 3000 ms. Параметр `PERIOD_MS` задаёт период SENSOR отдельно.
3. Исправлен расчёт числа 20-ms системных тиков для задержки без переполнения
   выражения `delay_ms+19`.

PIT 50 Hz не изменён. Поэтому при текущей временной базе минимально представимый
период SENSOR — 20 ms; `10 ms` на этой стадии округляется вверх до одного PIT-тика.
Это сделано намеренно, чтобы не менять существующую временную модель ToyOS.
