# ToyOS v67 RTD — Stage 3 FIX1

## Ошибка

Команда:

    exec RTD.EXE SENSOR.EXE 20 20 3

возвращала:

    RTD: start FAIL code=4294967295

Код `4294967295` является представлением `-1`, то есть `EXE_ERR_BUSY`.

## Причина

В Stage 3 поиск свободного RT-слота проверял только состояния:

- `TASK_STOPPED`;
- `TASK_EXIT`.

После инициализации ядра существующие записи `sched_tasks[]` имеют состояние
`TASK_CREATE` (нулевое значение), а не `TASK_STOPPED`. Поэтому до первого
создания RT-задачи все четыре RT-слота ошибочно считались занятыми.

Stage 2 не содержал этой ошибки, потому что непосредственно использовал слот
0 и перед загрузкой сам обнулял его запись.

## Исправление

Свободным RT-слотом теперь считается также `TASK_CREATE`.

Изменён только критерий выбора свободного слота:

    TASK_CREATE | TASK_STOPPED | TASK_EXIT

Остальная логика Stage 3 не изменялась.

## Возврат к стабильной базе

Контекст shell, ESC, `SYS_RT_WAIT`, периодическая работа, deadline и существующий
PIT 50 Hz не изменялись.

Это исправление не требует отката к Stage 2 FIX2.
