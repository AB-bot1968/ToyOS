# ToyOS v67 RTD — Stage 3 FIX1 — тест-план

## 1. Статическая проверка

Проверить в `src/kernel.c`, что поиск слота допускает:

    TASK_CREATE
    TASK_STOPPED
    TASK_EXIT

## 2. Первая RT-задача

Выполнить:

    exec RTD.EXE SENSOR.EXE 20 20 3

Ожидание: `RTD: started ...`, затем `SENSOR: tick`.

## 3. ESC

Нажать ESC.

Ожидание:

    SENSOR: ESC -> stopped
    toy0>

## 4. Вторая RT-задача

Сначала снова запустить одну задачу, затем из shell выполнить вторую команду:

    exec RTD.EXE SENSOR.EXE 40 40 7

Ожидание: две независимые задачи занимают разные RT-слоты и продолжают
работать одновременно.

## 5. Предельное количество

Последовательно занять четыре RT-слота. Пятая попытка должна вернуть
`EXE_ERR_BUSY`.
