# ToyOS v67 RTD — Stage 3 FIX2 — отчёт верификации

## Исходная ошибка

Stage 3 FIX1 зависал при первом запуске detached RT-задачи.

## Исправленный участок

`src/kernel.c`, `sched_irq_tick()`:

- безопасное сохранение Ring-3 frame;
- явная обработка `budget_hit`;
- RT->RT только при наличии другой готовой задачи;
- RT->shell после исчерпания budget, когда другой RT job отсутствует.

## Статические проверки

    RTD stage 3 checks passed
    RTD stage 3 FIX1 checks passed
    RTD stage 3 FIX2 checks passed

## Компиляция

Проверены 32-bit freestanding:

    src/kernel.c       PASS
    src/user_shell.c   PASS
    src/rtd.c          PASS
    src/rt_sensor.c    PASS

Ожидаемое старое предупреждение `fat_find_free_dir` остаётся существующим и
не относится к RTD FIX2.

## Сборка образа

Локальная адаптированная сборка создаёт FAT16-образ и проверяет наличие
`RTD.EXE`/`SENSOR.EXE`.

Окружение не содержит `qemu-system-i386`, поэтому аппаратный runtime не
утверждается как локально подтверждённый.

## Регрессионные замечания

Часть исторических `check*.sh` использует точное совпадение со старыми
формулировками исходного кода и потому может давать ложные FAIL после
архитектурных изменений. Такие случаи должны отличаться от функционального
runtime-регресса.
