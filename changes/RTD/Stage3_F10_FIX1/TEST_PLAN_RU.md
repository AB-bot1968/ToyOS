# План тестирования Stage3 F10 FIX1

## 1. Статические проверки

Запустить:

`sh check_vga_text_shell_userdata.sh`

Ожидание: все проверки `PASS`.

## 2. Возврат VGADRV → text mode

Запустить:

`exec VGADRV.EXE SPLASH.RAW`

Нажать клавишу возврата в text mode.

Ожидание: нет `EXC 14`, появляется рабочий shell.

## 3. F10 путь

Выполнить:

`exec RTD.EXE SENSOR.EXE 20 20 3`

Ожидание: задача только подготавливается, shell остаётся доступен.

Нажать F10.

Ожидание: задача запускается без page fault.

## 4. Второй запуск

Подготовить вторую RT-задачу:

`exec RTD.EXE SENSOR.EXE 40 40 3`

Затем F10.

Ожидание: первая и вторая RT-задачи работают согласно Stage 3.

## 5. ESC

Для активной задачи нажать ESC.

Ожидание: `SENSOR: ESC -> stopped`, после завершения последней RT-задачи — `toy0>`.

## 6. Регрессия

Не должны измениться PIT 50 Hz, обычный EXE1 loader, EXECMT и обработка VGA syscall 32/33/35.
