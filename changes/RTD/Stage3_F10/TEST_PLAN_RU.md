# ToyOS v67 RTD Stage 3 F10 — план тестирования

## Тест 1 — одиночная заявка

Ввести:

```text
exec RTD.EXE SENSOR.EXE 20 20 3
```

Ожидание: `SENSOR.EXE` НЕ начинает выдавать `tick`.

Shell печатает сообщение `RTD: task prepared...` и новое приглашение `toy0>`.

## Тест 2 — две заявки до F10

Ввести:

```text
exec RTD.EXE SENSOR.EXE 20 20 3
exec RTD.EXE SENSOR.EXE 40 40 3
```

До F10 ни одна задача не должна быть запущена.

После нажатия F10 должны быть запущены обе заявки.

## Тест 3 — четыре заявки

Подготовить четыре RT-команды. Пятая должна получить сообщение об заполненной очереди.

## Тест 4 — F10 без заявок

Нажать F10 без подготовленных задач.

Ожидание:

```text
RTD: no queued tasks
```

## Тест 5 — ESC после запуска

После F10 дождаться `SENSOR: tick`, затем ESC.

Сохранённое поведение:

```text
SENSOR: ESC -> stopped
toy0>
```

## Тест 6 — задержка

Подготовить:

```text
exec RTD.EXE SENSOR.EXE 20 20 3 3000
```

Нажать F10. Задержка `3000 ms` должна применяться штатным RTD перед стартом соответствующей задачи.

## Тест 7 — регрессия shell

Проверить `help`, `ls`, `ticks`, `exec` и существующие команды после F10.
