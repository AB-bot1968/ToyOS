# Toy OS v60 — release notes

## Этап

Первый этап развития иерархической FAT16 filesystem.

## Новые возможности

- каталоги FAT16 (`ATTR_DIRECTORY=0x10`);
- абсолютные пути `/DIR/FILE.TXT`;
- вложенные каталоги произвольной глубины в пределах ограничений 8.3 и FAT16;
- `mkdir PATH`;
- `rmdir PATH` для пустых каталогов;
- `ls PATH`;
- чтение, запись, append, delete, filesize и exec по вложенным путям;
- автоматическое расширение каталога новым кластером при нехватке directory entries;
- `mkfat16` создаёт каталоги при упаковке образа;
- `fat16check` проверяет каталоги, пути и зеркала обеих FAT.

## Совместимость

Существующий `SYS_LS=24` сохранён. Вызов с `EBX=0` показывает ROOT.
Существующий `SYS_FILE_*` ABI не перенумерован. Добавлены только:

- `SYS_MKDIR=27`;
- `SYS_RMDIR=28`.

EXE1, scheduler, COMDRV, LOADER и NETDRV архитектурно сохранены.

## Ограничения

LFN, cwd, `cd`, `pwd`, `opendir/readdir` и рекурсивное удаление не входят в v60.
Следующий этап — v61.
