# Toy OS v66.7 — исправление управления Slave и диагностики UDP

## Исправления

1. `ESC` теперь останавливает `NETDRV.EXE TELEMETRY SLAVE1|SLAVE2`.
2. Slave после `ARP failed` не завершается, а повторяет ARP.
3. Первый UDP пакет отправляется сразу после успешного ARP.
4. Добавлена явная диагностика `UDP TX N` и `UDP TX failed; retry ARP`.
5. Текущее состояние Slave отображается в одной строке экрана и не накапливается.

## Важно

Исправление программы не заменяет настройку маршрутизации Windows 7. Для межкомпьютерной передачи через Wi-Fi должны быть правильно настроены IP адрес TAP, IP forwarding и статические маршруты согласно `TEST_PLAN_V66_3_WIFI_RU.md`.
