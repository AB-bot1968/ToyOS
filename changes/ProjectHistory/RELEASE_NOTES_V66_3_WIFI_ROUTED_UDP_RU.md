# Toy OS v66.3 — UDP Telemetry через Wi-Fi без L2 Bridge

v66.3 продолжает v66.2 и сохраняет рабочую основу v65.15.

## Основное изменение

UDP-телеметрия теперь рассчитана на IP-маршрутизацию Windows 7 между QEMU/TAP и обычной Wi-Fi сетью. Windows Network Bridge не требуется.

На Slave при удалённом Master код теперь выбирает адрес `GATEWAY` как ARP target, а IP назначения UDP остаётся адресом Master. Это исправляет неверное требование ARP удалённого Toy OS-адреса через локальный Ethernet-сегмент.

## Сохранено

- NE2000 ISA.
- ARP.
- IPv4.
- UDP/5000.
- независимая работа Slave.
- ESC для остановки Master.
- фиксированные экранные области без накопления строк.
- FAT16, loader, splash и остальные функции v65.15.

## Сетевая адресация v66.3

ПК №1 / Master:

- TAP Windows: `10.66.1.1/24`.
- Toy OS Master: `10.66.1.2/24`.

ПК №2 / Slave:

- TAP Windows: `10.66.2.1/24`.
- Toy OS Slave1: `10.66.2.2/24`.
- Toy OS Slave2: `10.66.2.3/24`.

Реальные Wi-Fi IP компьютеров остаются адресами вашей обычной Wi-Fi сети и задаются только в Windows static routes.
