# Toy OS v60.2 — протокол проверки

## 1. Исправление ROOT

Проверено, что построитель использует все 512 записей FAT16 ROOT DIRECTORY, а не
только 16 записей первого сектора.

## 2. Компиляция

`mkfat16.c` проверяется тремя независимыми проходами:

- `gcc -fsyntax-only`;
- обычная компиляция объекта;
- компиляция объекта с `-fno-omit-frame-pointer`.

Для kernel/user filesystem layer существующие проверки v60/v60.1 сохраняются.

## 3. Состав образа

Корневые записи проверяются для `BOOT.BIN`, `HELLO.EXE`, `COMDRV.EXE`,
`LOADER.EXE`, `NETDRV.EXE`, `NET.CFG` и тестовых EXE1.

Вложенные записи проверяются для `BIN/HELLO.EXE`, `BIN/NETDRV.EXE` и
`DOC/NET.CFG`.

## 4. Ограничение среды

Разработчик проекта требует Windows 7 + W64DevKit x86. Если этот toolchain
не установлен в текущей среде исполнения, результат нативной Windows-сборки
не выдумывается: пользователь должен дополнительно выполнить `build.bat` в
своей целевой среде.
