# Проверка v37 — scheduler с состояниями задач

v37 сохраняет требования v1..v36 и добавляет общий kernel-side scheduler.

## Что проверяется

1. Есть массив scheduler-задач.
2. У каждой задачи есть 19-словный CPU context и отдельный CR3.
3. Состояния: READY, RUNNING, STOPPED.
4. IRQ0 сохраняет текущий context.
5. Выбранная задача получает RUNNING, предыдущая — READY.
6. Выбор выполняется round-robin среди не остановленных задач.
7. При переключении загружается CR3 выбранной задачи.
8. При завершении теста восстанавливаются CR3 и context shell.
9. Исходный `struct frame` не изменён.
10. Реальный тест памяти v36 остаётся в пользовательском `mt-test`.

## Локальная проверка

`check30.sh` ... `check36.sh` должны оставаться PASS.
`check37.sh` проверяет scheduler state/context/CR3 и отсутствие изменения
архитектурного interrupt frame.

Полный PE/COFF build W64DevKit и запуск QEMU в среде разработки не заявляются
как выполненные, если соответствующее окружение недоступно.
