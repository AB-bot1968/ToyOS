# Проверка v35 — раздельные адресные пространства / CR3

## Цель

v35 продолжает эксперимент v34 с двумя тестовыми Ring-3 задачами A/B, но впервые переключает CR3 на каждом вытеснении IRQ0. Полный EXE1 scheduler и `execq` не изменяются.

## Что проверяется

1. Существуют два page directory и две page table.
2. A и B используют одинаковый виртуальный layout.
3. Виртуальный стек `0x003fd000` отображён в разные физические страницы A/B.
4. Сохраняются те же фиксированные 19 слов архитектурного контекста.
5. CR3 хранится отдельно от 19-словного frame.
6. IRQ0 сохраняет текущий frame, переключает A/B, загружает CR3 и восстанавливает следующий frame.
7. `SYS_MT_STOP` восстанавливает shell frame и shell CR3.
8. `execq` syscall 15/16 и глубина очереди остаются без изменений.

## Команда

В shell: `mt-test`. Ожидается вывод A/B с продолжением работы после переключений IRQ0. Тест A завершает эксперимент через syscall 19.

## Ограничения

В текущем окружении не заявляется полноценный W64DevKit PE/COFF + QEMU runtime. Локально проверяются исходная структура, 32-битная компиляция и статические проверки.
