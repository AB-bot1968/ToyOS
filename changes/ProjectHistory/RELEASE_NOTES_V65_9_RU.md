# Toy OS v65.9 — исправление артефактов text mode

В v65.9 исправлена причина, из-за которой после `exec VGADRV.EXE SPLASH.RAW` заставка исчезала, но текстовый режим оставался фактически графическим или показывал нечитаемые символы.

## Причина

VGA Mode 13h с Chain-4 использует все четыре video plane. Plane 2 содержит bitmap-шрифт VGA text mode. Запись 64000 байт изображения затирала этот шрифт. Поэтому одного восстановления CRTC/Sequencer было недостаточно. Кроме того, для стандартного mode 03h Sequencer Memory Mode должен быть 0x07.

## Исправление

- при запуске kernel сохраняет BIOS/VGA 8x16 font из plane 2 в RAM (4096 байт);
- при `SYS_VIDEO_TEXT` сначала программируется стандартный цветной VGA mode 03h 80x25;
- затем исходный font plane 2 восстанавливается через специальный VGA addressing mode;
- только после этого очищается `0xB8000` и обновляется курсор;
- значение Sequencer Memory Mode исправлено на `0x07`;
- таблица Attribute Controller для Mode 13h дополнена всеми 21 регистрами;
- `SPLASH.RAW` остаётся нативным 320x200x256, 64000 байт, без 2x2 масштабирования.

## Проверка

Добавлены `check91.sh` и `check92.sh` для контроля сохранения шрифта, порядка восстановления VGA и точных таблиц регистров.
