# Toy OS v60.4 — исправление остановки сборки после MT25.EXE

## Причина

В предыдущей версии `mkfat16` при аргументе без `=` использовал весь путь
хостового файла как путь назначения FAT16. Например:

`build/MT25.EXE`

ошибочно трактовался как путь FAT16 `build/MT25.EXE` вместо файла
`MT25.EXE` в ROOT.

При этом создавались лишние каталоги `build/...`; каталог с большим числом
файлов мог переполнить один кластер. В результате сборка останавливалась
после создания `MT25.EXE`, а `disk.img` не появлялся.

## Исправление

Теперь правило однозначно:

- `HOSTFILE` → `basename(HOSTFILE)` в ROOT;
- `HOSTFILE=DESTPATH` → точный путь `DESTPATH` в FAT16.

Также `build.sh` теперь явно задаёт назначения для всех корневых системных
файлов и немедленно проверяет наличие `build/disk.img` после `mkfat16`.

## Состав ROOT

В корне образа находятся загрузчик/образ загрузочного сектора, все системные
EXE, все `MT01.EXE ... MT25.EXE` и `NET.CFG`.

Каталоги v60 сохраняются:

- `BIN/HELLO.EXE`
- `BIN/NETDRV.EXE`
- `DOC/NET.CFG`

## Проверки

Добавлен `check64.sh` — тройная проверка исходника, три компиляционных
прохода и регрессионное создание образа с `MT25.EXE`.

Полная сборка Windows 7 + W64DevKit x86 должна быть выполнена в целевой
среде; текущая Linux-среда не объявляется эквивалентом Windows-сборки.
