# Проверка Toy OS v65.4

## Цель

Проверить исправление ошибки, при которой правильная команда
`exec VGADRV.EXE SPLASH.RAW` завершалась собственным сообщением `usage`.

## Выполненные проверки

1. `src/vgadrv.c` проверен на отсутствие старого пустого inline-asm для EDX.
2. `program_main()` имеет явный cdecl ABI с тремя аргументами.
3. `_start` передаёт аргументы в правильном порядке: EDX, ECX, EBX перед `call`.
4. VGADRV собран в 32-битном freestanding режиме с `-Wall -Wextra -Werror`.
5. VGADRV связан через `ld -m i386pe`, затем `objcopy` создаёт RAW.
6. Начало PE-образа дизассемблировано: после `_start` находятся три `push` и `call _program_main`.
7. EXE1 остаётся с entry `0x00100000`.
8. `SPLASH.RAW` остаётся обычным FAT16-файлом размером 64000 байт.
9. Исторические проверки v62-v64 и проверки v65 выполняются без изменения их контрактов.

## Ограничение среды

Полный запуск Windows 7 + W64DevKit x86 + QEMU из текущей Linux-среды не
выполнялся. Это не выдаётся за фактически выполненный тест.
