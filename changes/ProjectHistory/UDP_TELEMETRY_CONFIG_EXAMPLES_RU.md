# Примеры NET.CFG для трёх машин

Каждая машина должна иметь **свой MAC** и **свой IP**. В v66.1 три конфигурации уже входят в FAT16 и выбираются автоматически по роли `MASTER`, `SLAVE1` или `SLAVE2`. Старый `NET.CFG` v65.15 сохраняется для прежних TCP/HTTP тестов.

## MASTER — 192.168.100.10

```text
BASE=300
MAC=52:54:00:10:00:10
IP=192.168.100.10
MASK=255.255.255.0
GATEWAY=192.168.100.1
PORT=8080
PATH=/
TIMEOUT=10
```

Запуск: `exec NETDRV.EXE TELEMETRY MASTER 5000`

## SLAVE1 — 192.168.100.11

```text
BASE=300
MAC=52:54:00:10:00:11
IP=192.168.100.11
MASK=255.255.255.0
GATEWAY=192.168.100.1
PORT=8080
PATH=/
TIMEOUT=10
```

Запуск: `exec NETDRV.EXE TELEMETRY SLAVE1 192.168.100.10`

## SLAVE2 — 192.168.100.12

```text
BASE=300
MAC=52:54:00:10:00:12
IP=192.168.100.12
MASK=255.255.255.0
GATEWAY=192.168.100.1
PORT=8080
PATH=/
TIMEOUT=10
```

Запуск: `exec NETDRV.EXE TELEMETRY SLAVE2 192.168.100.10`

Для текущего драйвера QEMU используется `ne2k_isa` с базой `0x300`; `rtl8139` пока не поддерживается этим драйвером.

В v66.1 эти три файла (`NET_MAST.CFG`, `NET_SLV1.CFG`, `NET_SLV2.CFG`) автоматически включаются в образ. `SET_NET_M.BAT`, `SET_NET_1.BAT` и `SET_NET_2.BAT` больше не нужны для телеметрии и оставлены только как справочные файлы. Все три машины можно собирать из одного и того же исходного архива: роль команды `TELEMETRY` определяет нужный конфигурационный файл.
