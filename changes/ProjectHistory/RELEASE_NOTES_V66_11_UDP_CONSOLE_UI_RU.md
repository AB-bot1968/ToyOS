# Toy OS v66.11 — переработка консоли UDP-телеметрии

v66.11 зафиксирована как следующая версия после проверенной v66.10. Сетевой протокол и успешная передача UDP не меняются по смыслу: переработан только экранный dashboard Master/Slave и способ обновления его полей.

## Master

Master больше не выводит каждую служебную строку через обычную консоль с прокруткой. Используется фиксированный dashboard VGA:

- заголовок и локальный IP Master;
- отдельный блок SLAVE1;
- отдельный блок SLAVE2;
- состояние WAITING/ONLINE;
- счётчик принятых UDP-пакетов RX;
- последняя принятая строка телеметрии DATA;
- сетевой статус и подсказка ESC.

Каждое поле перерисовывается на прежнем месте, поэтому история пакетов не накапливается.

## Slave

Slave получает симметричный dashboard:

- роль и локальный IP;
- IP Master;
- состояние ARP;
- количество отправленных пакетов;
- последняя отправленная телеметрия;
- используемый путь routed Wi-Fi / TAP / NE2000;
- остановка по ESC.

## Совместимость

Команды остаются прежними:

```text
exec NETDRV.EXE TELEMETRY MASTER 5000
exec NETDRV.EXE TELEMETRY SLAVE1 10.66.1.2
exec NETDRV.EXE TELEMETRY SLAVE2 10.66.1.2
```

UDP/5000, адреса 10.66.1.0/24 и 10.66.2.0/24, текущая NE2000 и маршрутизированная Wi-Fi схема не заменяются.
