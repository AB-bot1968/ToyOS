# Toy OS v61 — baseline

v61 сохраняет BIOS/protected mode, Ring-3, paging, INT 80h, FAT16, EXE1, scheduler,
NETDRV и иерархические каталоги v60.

## Новое

- `SYS_CHDIR=29`: `EBX=PATH`, проверяет каталог и устанавливает cwd.
- `SYS_GETCWD=30`: `EBX=BUFFER`, `ECX=CAPACITY`, возвращает длину пути без NUL.
- Относительные пути разрешаются относительно cwd.
- `.` и `..` нормализуются без изменения FAT16 на диске.
- Shell: `cd PATH`, `pwd`, `cwd-test`.
