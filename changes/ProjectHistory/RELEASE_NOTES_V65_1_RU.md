# Toy OS v65.1 — исправление сборки SPLASH.RAW

## Исправление

В v65 сборка формировала ресурс как `resources/SPLASH.RAW`, но команда
`mkfat16` получала имя `build/SPLASH.RAW`. Между этими этапами файл в
`build/` не создавался, поэтому строгий `set -eu` останавливал сборку при
добавлении графического файла в FAT16.

В v65.1 `build.sh` теперь явно:

1. проверяет наличие `resources/SPLASH.RAW`;
2. копирует его в `build/SPLASH.RAW`;
3. проверяет существование и размер staging-файла;
4. только после этого передаёт `build/SPLASH.RAW=SPLASH.RAW` утилите `mkfat16`.

Остальная архитектура v65 не изменена: `SPLASH.RAW` остаётся обычным FAT16-файлом,
а `VGADRV.EXE` — отдельным Ring-3 приложением.
