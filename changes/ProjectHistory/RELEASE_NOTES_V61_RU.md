# Toy OS v61 — рабочий каталог shell (cwd), cd/pwd и нормализация путей

## Цель этапа

v61 завершает запланированное расширение v60: интерактивный Ring-3 shell получает
рабочий каталог, команды `cd` и `pwd`, а все существующие FAT16 операции начинают
понимать относительные пути. Формат FAT16, layout образа и 8.3 остаются без изменений.

## Реализация

- `SYS_CHDIR=29` проверяет каталог и меняет kernel-side `cwd`.
- `SYS_GETCWD=30` возвращает канонический абсолютный путь в пользовательский буфер.
- `fat_normalize_path()` объединяет относительный путь с cwd и обрабатывает `.`, `..` и повторные `/`.
- После нормализации компоненты проходят обычную проверку FAT16 8.3.
- `ls`, `cat`, `read`, `write`, `append`, `delete`, `filesize`, `exec`, `execmt`, `execq`, `mkdir`, `rmdir` и аргументы COMDRV/LOADER/NETDRV получают естественное поведение относительно cwd, поскольку используют общий FAT path resolver.
- Абсолютные пути `/...` по-прежнему обходят cwd.
- Переход выше ROOT (`cd ..` в `/`) остаётся в `/`.
- `cwd-test` проверяет `/BIN`, `./../BIN/./`, `..`, `pwd` и относительный `ls`.

## Ограничения

- cwd глобален для текущей реализации ядра, поскольку Toy OS пока не имеет полноценного процесса с отдельным POSIX-like address space/cwd для каждого процесса.
- LFN не добавляется; сохраняется FAT16 8.3.
- `cd` не создаёт каталоги и не изменяет дисковую структуру.
