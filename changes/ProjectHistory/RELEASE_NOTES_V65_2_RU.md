# Toy OS v65.2 — исправление запуска VGADRV.EXE

## Причина ошибки EXC 13

В v65/v65.1 точка входа `VGADRV.EXE` содержала дальний переход:
`jmpl $0x08, $_program_main`. Селектор `0x08` соответствует Ring 0
(kernel code segment), поэтому запущенная из Ring 3 программа немедленно
получала #GP: `EXC 13 ... ERR=8`. Ошибка возникала до выполнения
`program_main()`.

## Исправление

Точка входа `VGADRV.EXE` теперь использует обычный переход внутри
текущего пользовательского code segment:

```asm
_start:
    jmp _program_main
```

Селектор Ring 0 больше не используется. Формат EXE1 и адрес загрузки
`0x00100000` не изменялись.

## Регрессия

Добавлен `check79.sh`, который запрещает возвращение привилегированного
far-jump в исходник VGADRV и проверяет сохранение ABI EXE1. `build.sh`
теперь выполняет `check78.sh` и `check79.sh`.

## Проверка

- `check68.sh`–`check78.sh` — PASS.
- `check79.sh` — PASS.
- Все 32-битные freestanding C-исходники проекта — PASS.
- Все 25 экземпляров `execmt_task.c` — PASS.
- `boot.S`, `isr.S` — PASS.
- VGADRV собран, слинкован в i386 PE и упакован в EXE1 — PASS.
- Заголовок EXE1: entry `0x00100000`, image size соответствует файлу — PASS.
- Первые байты VGADRV теперь соответствуют обычному относительному `jmp`,
  а ошибочный `EA 08 00 00 00` отсутствует — PASS.

Полный запуск в Windows 7/W64DevKit x86/QEMU в текущей среде невозможен:
локальная среда Linux x86_64 и не содержит требуемый i686 W64DevKit.
