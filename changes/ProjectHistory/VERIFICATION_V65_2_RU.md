# Toy OS v65.2 — отчёт проверки

## Исправленная ошибка

`exec VGADRV.EXE SPLASH.RAW` приводил к:
`EXC 13 EIP=1048576 CS=27 ERR=8`.

Диагностика однозначна: `EIP=0x00100000` совпадает с адресом EXE1 entry,
а `ERR=8` — селектор `0x0008`. В старой точке входа VGADRV был выполнен
`jmpl $0x08, $_program_main`, то есть Ring 3 пытался выполнить переход
на кодовый сегмент Ring 0. CPU отвергал такой переход #GP.

Исправлено на обычный `jmp _program_main`, не меняющий CS и CPL.

## Тест на целевой машине

На Windows 7 + W64DevKit x86 после распаковки выполнить:

```text
build.bat
```

Затем в Toy OS:

```text
exec VGADRV.EXE SPLASH.RAW
```

Ожидаемый результат: больше нет `EXC 13 ... ERR=8`; VGADRV начинает
выполнение, загружает `SPLASH.RAW` и переходит в графический режим. После
клавиши драйвер восстанавливает текстовый режим и печатает `VGADRV: OK`.
