# NETDRV v58.7 — исправление пустого PAGE.TXT

Исправлен путь RECV после успешного TCP/HTTP соединения.

Причина предыдущей версии: успешное завершение `RECV` не гарантировало,
что тело HTTP-ответа было реально записано через `SYS_FILE_WRITE`. Обработка
TCP DATA/FIN и проверка результата были недостаточно строгими.

Исправления:
- потоковая обработка HTTP-заголовка, включая разрыв `\r\n\r\n` между TCP-сегментами;
- тело, находящееся после конца заголовка в том же сегменте, сразу передаётся
  в `SYS_FILE_WRITE`;
- каждый последующий DATA-сегмент также записывается;
- дубликаты TCP-сегментов не записываются повторно;
- FIN с DATA обрабатывается после записи DATA;
- FIN без DATA подтверждается отдельно;
- после закрытия файла вызывается `SYS_FILE_SIZE` и сравнивается фактический
  размер с числом реально записанных байт;
- при ошибке `SYS_FILE_WRITE`, `SYS_FILE_SIZE` или несовпадении размера
  NETDRV больше не сообщает ложное `RECV page saved`;
- добавлен `SYS_FILE_SIZE = 17` в ABI-константы NETDRV;
- существующие syscall ABI ядра не изменены.

Проверено 3 компиляциями `src/netdrv.c` в 32-битном режиме GCC:
PASS1, PASS2, PASS3.

Полный runtime QEMU/W64DevKit в среде разработки недоступен; запуск должен
быть выполнен на целевой Windows 7/W64DevKit системе.
